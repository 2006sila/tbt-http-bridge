# HostSim —— 离线宿主夹具

不需要安装 ThinkBook Toolkit：夹具按宿主真实行为构造 `PluginRequest`、驱动 `EvaluateAsync`、
「执行」插件交回的 `HostCommand`，同时用真实 HTTP 请求打插件端口，并用与 `PluginHost` 相同的
`AssemblyLoadContext` 逻辑加载**打包后的** DLL。

~~~cmd
test.cmd          :: 仓库根目录执行：构建 + 运行全部断言
~~~

覆盖：快照字段与 null 规则、`ItsMode` 数字→名称、三条控制路由的命令内容、错误码与逐字文案、
能力门禁、端口切换与释放、队列上限、畸形流量、`Dispose` 后端口释放 —— 共 39 项。

## 端口约定（重要）

夹具固定使用 **3299 / 3399**。

> ⚠️ **绝不要改成 2975**。真机插件的默认端口就是 2975：夹具一旦连上正在运行的真实插件，
> 洪泛类用例（300 条并发控制请求）会把命令打进**真实硬件**——曾经因此让笔记本风扇全速跑了约 2 分钟。

夹具在启动后还会做一次自检：`GET /` 的 `cpuTemperatureC` 必须等于自己的假数据（61.5），
否则立刻中止，避免误操作真机。
